TRON OS

Assistente pessoal de voz para Windows, de uso privado, usado apenas pelo próprio desenvolvedor.

Política de Privacidade

O TRON OS acessa Gmail, Google Agenda e Contatos somente nas contas Google do próprio usuário, mediante sua autorização explícita, e apenas para executar comandos solicitados por ele.

Os dados são processados localmente no computador do usuário. Eles não são vendidos, compartilhados com terceiros nem armazenados em servidores externos.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
